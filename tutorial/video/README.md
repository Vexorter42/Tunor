# Видео про Tunor

Два ролика из тех же анимаций, что в обучении: вертикальный (TikTok, около минуты, крупные титры) и
горизонтальный (YouTube, три-четыре минуты, с главами). Что в них говорится и показывается — в
[`storyboard.py`](storyboard.py), там же тексты, которые читает автор.

## Как это собирается

Нужны Python с Pillow и ffmpeg. Кадры рисует Pillow (анимации — тот же [`scenerender.py`](../scenerender.py),
что и в обучении), кодируется кусками на всех ядрах сразу и склеивается без перекодирования.

```bash
cd tutorial/video
python build.py text   tunor-tiktok        # сценарий для чтения, субтитры (.srt), главы
python build.py render tunor-tiktok        # немое видео с титрами
python build.py thumbs                     # обложки
python build.py sheet  tunor-youtube s.png # по кадру из каждого куска, чтобы глянуть целиком
```

Результат ложится в `out/`. Экраны обучения для кадров лежат в `shots/` (снимки настоящего окна в двойном
размере; обе папки в `.gitignore`).

## Как записать голос

Видео делается под запись: титры идут в том темпе, в каком читают вслух. Читай по абзацу сценария и делай
вдох между ними: пауза в секунду-полторы. Потом:

```bash
python build.py fit tunor-tiktok golos.wav
```

Команда находит в записи куски речи, по одному на строку сценария, подгоняет под них длительность
каждого куска, заново рисует видео, переписывает субтитры и кладёт голос поверх (громкость выравнивается).
Так работает, если читать ровно, с паузой между абзацами и без дублей.

### Если были дубли и оговорки

Человек, читающий вслух, сбивается и начинает заново; по паузам дубль от абзаца не отличить. Для этого есть
второй режим: запись **распознаётся** (офлайн, ничего никуда не отправляется), каждое предложение сценария
ищется в распознанном тексте, берётся лучший дубль (при равенстве — последний), сбои вырезаются, остальное
склеивается в порядке сценария с тишиной самой комнаты между кусками. Картинка подгоняется уже под чистую
дорожку.

```bash
pip install vosk        # лучше в отдельное окружение; его Python и передаётся в --asr-python
# модель: vosk-model-small-ru-0.22 с alphacephei.com/vosk/models, распаковать в любую папку
python build.py fit tunor-youtube golos.mkv --asr путь/к/vosk-model-small-ru-0.22 --asr-python путь/к/python
```

В конце команда печатает, где найдено каждое предложение и насколько оно совпало со сценарием; строки с
«??» стоит послушать. Английские слова модель «слышит» по-русски, поэтому у предложений с «WARP» или
«Cloudflare» совпадение ниже, на выбор дубля это почти не влияет. Файл записи может быть любым, что читает
ffmpeg (в том числе `.mkv` с экраном: берётся только звук).
