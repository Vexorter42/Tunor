# Tunor для Android

Ранняя версия: то же, что делает Tunor на компьютере, в объёме, который нужен телефону. Построена на движке
[sing-box-lx](https://github.com/Leadaxe/sing-box-lx), его библиотеке `libbox`, с AmneziaWG 1.0 / 2.0 / 3.x.

## Что есть

- **Туннели:** `.conf` WireGuard и AmneziaWG (файлом или текстом), ссылка `vless://`, подписка (адрес, который
  отдаёт список ссылок, обычным текстом или в base64) с выбором сервера.
- **Правила:** список сайтов, которые идут через туннель (адрес покрывает и поддомены), и выбор, какие приложения
  вообще пользуются VPN. Всё остальное идёт напрямую, скорость не страдает. Переключатель «весь трафик через
  туннель» для тех, кому нужно наоборот.
- **Проверка соединения:** спрашивает у Cloudflare, откуда виден запрос, через туннель и напрямую.
- **Журнал движка** на экране, условия использования при первом запуске.

## Чего пока нет

Обучения с вопросами (оно есть на компьютере), каталога готовых списков, слежения за стабильностью туннеля,
смены точки выхода WARP, ссылок `vmess://`, `trojan://`, `ss://` (только `vless://`), IPv6 (туннель и DNS
работают по IPv4: телефонная сеть часто объявляет IPv6, которым нельзя пользоваться), запуска при включении
телефона и обновления по воздуху (новая версия ставится APK поверх старой).

## Как это проверено

На эмуляторе Android 16 против локальных серверов на том же движке, поднятых на компьютере:

- VLESS-сервер: VPN поднимается, сайт из списка приходит на сервер, сайт не из списка идёт напрямую;
- AmneziaWG-сервер с обфускацией (`Jc`, `S1`, `S2`, `H1`–`H4`): рукопожатие проходит, трафик выходит через сервер;
- подписка, поданная по адресу, с серверами, названными кириллицей и пробелами;
- несколько включений и выключений подряд, релизная сборка со сжатием кода.

На настоящем телефоне и с настоящим WARP это ещё не проверялось.

## Сборка

Нужны JDK 17 или новее и Android SDK с платформой 36 (`ANDROID_HOME` указывает на него).

```bash
cd android
python fetch-libbox.py            # движок, 120 МБ: в репозитории его нет. Где GitHub медленный: --mirror https://gh-proxy.com/
./gradlew :app:assembleDebug      # или :app:assembleRelease
```

APK по одному на архитектуру лежат в `app/build/outputs/apk/`: `arm64-v8a` для телефонов, `x86_64` для эмулятора.
Движок `fetch-libbox.py` сверяет с контрольной суммой, записанной в нём самом, поэтому зеркало может его
принести, но не подменить. Обновить движок — изменить `VERSION` и `SHA256` в этом файле.

Подпись выпуска берётся из `signing.properties` (его нет в репозитории): `storeFile`, `storePassword`, `keyAlias`,
`keyPassword`. Без него релиз подписывается отладочным ключом: ставится, но публиковать такой нельзя. Ключ
нужно беречь: приложение, подписанное другим, не обновляется поверх старого.

`python make-icons.py` рисует значок из логотипа приложения для компьютера.
