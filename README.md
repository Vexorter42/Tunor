# Tunor

Графический интерфейс для [sing-box](https://github.com/SagerNet/sing-box) на Windows с поддержкой **AmneziaWG 1.0 / 2.0 / 3.x**: управление туннелем, правила маршрутизации, помощники генерации конфигов и обновление «по воздуху».

> A Windows GUI for sing-box with AmneziaWG (1.0 / 2.0 / 3.x) — tunnel control, routing rules, guided config generation and OTA updates.

До версии 1.10.0 проект назывался **Nyx**; имя сменилось из-за большого числа одноимённых проектов. Старые ссылки на репозиторий продолжают работать.

## Что умеет

**Туннели**

- **AmneziaWG 1.0 / 2.0 / 3.x** — движок на базе [sing-box-lx](https://github.com/Leadaxe/sing-box-lx). Поддерживаются `Jc/Jmin/Jmax`, `S1–S4`, `H1–H4`, `I1–I5`, а также 3.x: `ContentPaddingAddition`, `RekeyAfterTime`, `RejectAfterTime`, `KeepaliveTimeout`, `MaxHandshakeAttempts`, `RandomTrailers`, `DisableCookies`.
- **Два туннеля** — основной WARP и необязательный geo для сервисов, которым важна страна выхода. geo идёт цепочкой через WARP.
- **Сломанный конфиг не роняет второй туннель.** Ключи проверяются до сборки конфига: туннель с испорченным ключом не попадает в конфиг, а приложение говорит, что именно с ним не так — кавычки, невидимый символ, обрезанный ключ.
- **Свой генератор конфига** — `config.json` собирается приложением из `warp.conf`, `geo.conf`, `rules.json` и `settings.json`. Внешние утилиты не нужны.

**Маршрутизация**

- **Правила** — группы `inline` (домены и программы), `remote` (внешние `.srs`) и `local` (локальные списки). Домен в списке покрывает и поддомены: `youtube.com` включает `www.youtube.com`, но не `notyoutube.com`.
- **«Куда пойдёт»** — вписываешь домен, ссылку, IP или имя программы и сразу видишь, каким путём он пойдёт и какое правило сработало.
- **Раздел «Приложения»** — показывает, к каким доменам и адресам ходит каждая программа, и отправляет её целиком в WARP или geo одной кнопкой. Правило пишется по имени файла, поэтому переживает перезапуск программы.
- **Раздел «Соединения»** — что идёт через туннель прямо сейчас: адрес, маршрут, программа, объём и скорость.

**Повседневное**

- **Проверка соединения** — один запрос напрямую, через WARP и через geo; показывает IP выхода, страну и видит ли Cloudflare WARP.
- **Добавить конфиг** — кнопкой, перетаскиванием `.conf` на окно или через **Ctrl+V** (файлом или текстом). Конфиг распознаётся по содержимому, расширение значения не имеет.
- **Отчёт о проблеме** — одна кнопка в «Логах» собирает в файл версии, состояние туннелей, устройство конфига, состояние адаптера и лог. Ключи, секреты и содержимое личных списков в отчёт не попадают, так что его можно пересылать не читая.
- **Сторож** — поднимает движок, если он упал, и не пытается перезапускать то, что перезапуском не чинится. Если поднимать не будет — присылает уведомление в трей с причиной.
- **Профили конфигов** — несколько именованных `warp.conf` и `geo.conf` с переключением в один клик.
- **Автозапуск** свёрнутым в трей, **авто-перезапуск после сна**, **обновления по воздуху** с проверкой SHA256, тёмная тема, режим одного экземпляра.

## Установка

1. Скачай **`Tunor-Setup.exe`** со страницы [Releases](../../releases/latest).
2. Запусти установщик — нужны права администратора.
3. При первом запуске прими условия и пройди короткий туториал; там же кнопка **«Скачать списки»**.
4. Сгенерируй конфиг WARP в [@warp_generator_bot](https://t.me/warp_generator_bot) и добавь его: кнопкой **«Добавить файл .conf»** на «Главной», перетаскиванием на окно или через **Ctrl+V**.
5. *(необязательно)* Для geo — любой WireGuard-конфиг, тем же способом.
6. Нажми **«Запустить»**.

Установщик не содержит ничьих приватных ключей, личных списков доменов и самих файлов правил — всё настраивается и скачивается на месте.

## Какую версию AmneziaWG выбирать

Движок понимает все, так что выбирай любую:

| Версия | Параметры | Поддержка |
|---|---|---|
| AWG 1.0 | `S1–S4`, `Jc`, `Jmin`, `Jmax`, `H1–H4` | ✅ |
| AWG 2.0 | `I1–I5` | ✅ |
| AWG 3.0 | padding, rekey, reject, keepalive, handshake | ✅ |
| AWG 3.1 | `RandomTrailers`, `DisableCookies` | ✅ |

## Обновления по воздуху

Приложение читает `update.json` (репозиторий + зеркало), тянет `version.json` из последнего релиза и, если версия новее, скачивает установщик, сверяет `SHA256` и запускает тихую установку.

```json
{
  "repo": "Vexorter42/Tunor",
  "mirror": "https://ghproxy.net/"
}
```

Зеркало нужно там, где GitHub недоступен напрямую. Перестало работать — поменяй `mirror` (например на `https://ghfast.top/`), пересобирать ничего не нужно.

## Сборка из исходников

Нужен [.NET SDK 8+](https://dotnet.microsoft.com/download).

```bash
cd ui
dotnet build -c Debug
# или self-contained сборка:
dotnet publish -c Release -r win-x64 --self-contained true
```

Сборка установщика описана отдельно — см. [`packaging/README.md`](packaging/README.md).

Приложение ожидает такую структуру папок:

```
<корень>/
  settings.json            # режимы (tun / proxy / final / logging)
  update.json              # { "repo": "...", "mirror": "..." }
  THIRD-PARTY-NOTICES.md   # сведения о сторонних компонентах
  licenses/                # GPL-3.0.txt, sing-box-LICENSE.txt
  build/
    sing-box.exe           # движок (sing-box-lx, собран с тегом with_awg)
    sing-box.version       # какая это сборка движка и её sha256
    config.json            # генерируется приложением
  data/
    rules.json             # группы маршрутизации
    warp.conf              # AmneziaWG-конфиг WARP
    geo.conf               # WireGuard-конфиг geo
    rulesets/*.srs         # локальные списки (скачиваются приложением)
  ui/Tunor.exe             # это приложение
```
